# Python Data Analysis & Statistics

| # | Project | Highlights |
|---|---|---|
| 1 | [**EDA: Online Retail (real data)**](01-eda-online-retail) | 541K rows from UCI / Kaggle, documented cleaning, RFM, cohort retention |

Projects 3 and 4 use the same data as the [loan portfolio](https://github.com/ahmedsalamsali/powerbi-dashboards/tree/main/07-loan-portfolio-credit-risk) and [contact centre](https://github.com/ahmedsalamsali/powerbi-dashboards/tree/main/08-contact-center-cx) Power BI reports. The dashboard tells the story, and the notebook explains it with statistics.

**Stack:** Python · Pandas · NumPy · SciPy · statsmodels · Matplotlib · Seaborn · Jupyter
